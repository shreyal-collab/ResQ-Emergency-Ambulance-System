# ResQ – Emergency Ambulance Management System

## Project Description

ResQ is an Emergency Ambulance Management System designed to simplify and improve the process of requesting and managing ambulance services during medical emergencies.

The system provides a platform for users to request ambulance assistance and helps manage emergency requests efficiently. It uses the **Queue (FIFO – First In, First Out)** data structure to process requests in the order they are received.

## Technology Stack

- **Frontend:** React.js, JavaScript, CSS
- **Backend:** Java Spring Boot
- **Database:** MySQL
- **Data Structure:** Queue (FIFO)

## Objective

The main objective of ResQ is to provide an organized, user-friendly, and efficient approach to emergency ambulance management.
